# رادار ایردراپ | Airdrop Radar

یک داشبورد فارسی و راست‌چین برای فهرست‌کردن بازی‌های تلگرامی و فرصت‌های ایردراپ.

## امکانات فعلی
- رابط واکنش‌گرا و مناسب موبایل
- جست‌وجو، فیلتر دسته‌بندی و وضعیت، مرتب‌سازی
- نمایش لینک ورود، وب‌سایت و منبع بررسی
- نمایش جداگانه وضعیت پروژه و وضعیت Claim
- هشدارهای امنیتی درباره Seed Phrase، کلید خصوصی و امضای کیف پول
- اعتبارسنجی ساختار داده‌ها با GitHub Actions و انتشار GitHub Pages

## اجرای محلی
در ریشه پروژه:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## افزودن پروژه
فایل `data/opportunities.json` را ویرایش کنید. نمونه ساختار:
```json
{
  "id": "unique-project-id",
  "name": "Project name",
  "category": "Tap to Earn",
  "description": "توضیح مستند و کوتاه",
  "status": "در انتظار",
  "claim_status": "نامشخص",
  "token": "نامشخص",
  "network": "نامشخص",
  "cost": "رایگان",
  "platform": "Telegram",
  "entry_url": "https://t.me/example_bot",
  "website": "https://example.org",
  "telegram": "https://t.me/example_channel",
  "source_url": "https://example.org/official-announcement",
  "checked_at": "2026-11-05"
}
```

مقادیر `status`: «فعال»، «در انتظار»، «پایان‌یافته».
مقادیر `claim_status`: «قابل Claim»، «در انتظار»، «غیرفعال»، «نامشخص».

## راه‌اندازی انتشار
در GitHub مخزن را باز کنید:
1. از Settings → Pages، گزینه انتشار با GitHub Actions را انتخاب کنید.
2. در Actions، گردش‌کار Daily catalogue check and deploy را اجرا کنید.
3. پس از پایان موفق، آدرس Pages در بخش Settings → Pages نمایش داده می‌شود.

## مدل اعتماد و محدودیت‌ها
این نسخه وضعیت بازی‌ها را از روی حدس یا نام پروژه تولید نمی‌کند. اسکنر فعلی اعتبار ساختار داده و URLها را بررسی می‌کند؛ به‌تنهایی اعتبار پروژه، وعده ایردراپ یا موجودی توکن را تأیید نمی‌کند. برای افزودن هر پروژه، منبع رسمی و تاریخ بررسی انسانی لازم است. دایرکتوری‌ها و فهرست‌های عمومی صرفاً سرنخ‌اند، نه تأیید امنیت.

هرگز Seed Phrase یا کلید خصوصی را درخواست نکنید و هیچ پروژه‌ای را صرفاً به دلیل حضور در این سایت معتبر تلقی نکنید.


## کشف خودکار بازی‌های تلگرامی
- اسکریپت `discover.py` کاتالوگ عمومی `coolpac/telegram-mini-apps-catalog` را روزانه می‌خواند.
- فقط موارد دسته Games با وضعیت upstream برابر `ok` و لینک تلگرام وارد `data/discovery-candidates.json` می‌شوند.
- این وضعیت فقط نشان می‌دهد منبع بالادستی آن بازی را در فهرست خود فعال گزارش کرده است؛ به معنی تأیید ایردراپ، توکن، برداشت، امنیت یا سودآوری نیست.
- نامزدها در بخش جداگانه سایت نمایش داده می‌شوند تا با فرصت‌های تأییدشده اشتباه نشوند.
- فرصت‌های واقعی فقط پس از بررسی منبع رسمی پروژه و شواهد مستقل باید به `data/opportunities.json` اضافه شوند.
- اگر منبع بیرونی قطع شود، مرحله کشف شکست می‌خورد و داده ساختگی تولید نمی‌شود.
