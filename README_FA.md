# رادار ایردراپ | Airdrop Radar

داشبورد فارسی و راست‌چین برای پایش فرصت‌های ایردراپ، کمپین‌های پاداش و بازی‌های تلگرامی. این پروژه عمداً میان «فرصت دارای منبع» و «بازی صرفاً کشف‌شده» تفاوت می‌گذارد؛ امتیاز بازی، توکن یا درآمد تضمین‌شده نیست.

## امکانات
- رابط واکنش‌گرا و مناسب موبایل با جزئیات هر فرصت در پنجره جداگانه
- جست‌وجو، فیلتر وضعیت و شبکه، مرتب‌سازی بر اساس مهلت/نام/آخرین بررسی
- فیلتر سریع Claim، فرصت‌های بدون هزینه اعلام‌شده و مهلت‌های نزدیک
- نمایش شرایط واجدشرایط‌بودن، دارایی، شبکه، هزینه، مهلت، لینک رسمی و هشدار هر پروژه
- فهرست جداگانه بازی‌های کشف‌شده با برچسب «ایردراپ تأیید نشده»
- نصب‌پذیری وب‌اپ (PWA) و cache آفلاین برای پوسته و آخرین داده‌های دریافت‌شده
- اسکن روزانه کاتالوگ عمومی، اعتبارسنجی داده و انتشار خودکار GitHub Pages

## اجرای محلی
از ریشه پروژه اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. برای تست PWA و Service Worker از localhost یا HTTPS استفاده کنید.

## بروزرسانی خودکار
فایل `.github/workflows/daily-scan.yml` هر روز ساعت 05:15 UTC اجرا می‌شود و با اجرای دستی نیز قابل شروع است:
1. `discover.py` کاتالوگ عمومی بازی‌های تلگرامی را می‌خواند.
2. `scanner.py` ساختار فرصت‌ها، فیلدهای ضروری، URLها، شناسه‌های تکراری و وضعیت‌ها را اعتبارسنجی می‌کند و فرصت‌های منقضی را غیرفعال می‌کند.
3. HTML، جاوااسکریپت، Service Worker و فایل‌های JSON بررسی نحوی می‌شوند.
4. خروجی در GitHub Pages منتشر می‌شود.

این چرخه اطلاعات upstream را در artifact انتشار روزانه بازخوانی می‌کند؛ قرار نیست هر روز داده‌های ماشینی به‌عنوان commit تأییدشده وارد شاخه اصلی شوند.

## افزودن فرصت
فایل `data/opportunities.json` را ویرایش کنید. هر فرصت باید منبع رسمی قابل بازبینی داشته باشد. فیلدهای پیشنهادی:
- `id`, `name`, `category`, `description`
- `status`: یکی از «فعال»، «در انتظار»، «پایان‌یافته»
- `claim_status`: یکی از «قابل Claim»، «در انتظار»، «غیرفعال»، «نامشخص»
- `token`, `network`, `deadline`, `eligibility`, `cost`
- `entry_url`, `website`, `telegram`, `source_url`, `checked_at`
- `risk_note` برای ریسک‌ها و محدودیت‌های ویژه
- `contract_address` فقط وقتی آدرس قرارداد از منبع رسمی تأیید شده باشد.

هیچ داده‌ای را از روی حدس پر نکنید. برای نامعلوم‌ها «نامشخص» بنویسید. تاریخ‌ها با قالب ISO مانند `2026-12-31` باشند.

## کشف خودکار
- `discover.py` کاتالوگ [coolpac/telegram-mini-apps-catalog](https://github.com/coolpac/telegram-mini-apps-catalog) را می‌خواند.
- فقط اپ‌های Games با وضعیت upstream برابر `ok` و لینک `https://t.me/` وارد `data/discovery-candidates.json` می‌شوند.
- کشف‌شدن، به معنی تأیید ایردراپ، توکن، امکان برداشت، امنیت یا سودآوری نیست.
- فهرست‌های ثالث صرفاً سرنخ‌اند؛ برای ارتقای یک مورد به فرصت اصلی، اطلاعیه رسمی پروژه و شرایط روشن لازم است.
- اگر منبع بیرونی در دسترس نباشد، اسکریپت شکست می‌خورد و اطلاعات ساختگی جایگزین نمی‌کند.

## امنیت و محدودیت‌های مهم
- هیچ‌وقت Seed Phrase، کلید خصوصی، رمز عبور یا کد ورود را درخواست یا ثبت نکنید.
- پرداخت برای آزادسازی جایزه، وعده سود قطعی، لینک‌های تقلیدی و امضای تراکنش نامفهوم باید هشدار جدی تلقی شوند.
- وجود لینک یا نام یک پروژه در سایت، توصیه سرمایه‌گذاری یا تضمین امنیت نیست.
- اسکنر فعلی اعتبار ساختار و تاریخ را بررسی می‌کند؛ ممیزی قرارداد هوشمند، اثبات پرداخت، اعتبار حقوقی پروژه یا واجدشرایط‌بودن حساب‌ها را انجام نمی‌دهد.
- پنل مدیریت امن و ورود کاربران در این نسخه پیاده‌سازی نشده است؛ ویرایش داده‌ها از طریق مخزن GitHub انجام می‌شود. افزودن فرم مدیریت سمت مرورگر بدون backend و احراز هویت امن نیست.
